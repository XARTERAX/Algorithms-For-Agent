# Algorithms (for DMT students)

This repo is a personal algorithm & data-structure study space tailored to Digital Media Technology (DMT).

Structure:
- problems/: categorized problems + implementations + short reviews
- docs/: concise algorithm notes & patterns
- patterns/: reusable solution templates (sliding-window, DP, etc.)
- templates/: problem & solution templates
- DMT_projects/: small media-related projects to tie algorithms with multimedia
- tests/: sample inputs or unit tests

How to use:
1. Pick a topic in /problems and read the .md for idea + pseudocode.
2. Implement in your preferred language under implementations/<language>.
3. Add a 3–5 line "review" after solving: key idea, complexity, why correct.
4. For DMT projects, prefer Python + numpy/opencv for quick prototyping.

Contributing:
- Use templates/problem-template.md to add new problems.
- Filename format: 0001-two-sum.md ; implementation: 0001_two_sum.py
